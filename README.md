# Video Downloader (Android)

Мінімалістичний Android-застосунок українською мовою для завантаження прямих HTTP/HTTPS-посилань на відеофайли, які дозволено завантажувати.

## Можливості
- Android 7.0+ (minSdk 24), Kotlin не потрібен; Java + Android SDK.
- Перевірка прямого URL через HTTP HEAD та MIME `video/*` або типове розширення відеофайлу.
- Системний Android DownloadManager: завантаження у фоні та системне сповіщення.
- Історія, статус, розмір і відкриття завершеного файлу.
- Перемикач світлої/темної теми.
- Файли зберігаються у `Download`.

## Збірка APK через GitHub Actions
1. Створи порожній репозиторій GitHub, наприклад `video-downloader`.
2. Завантаж усі файли й папки цього проєкту в корінь репозиторію (включно з `.github/workflows/build.yml`).
3. Відкрий вкладку **Actions** і вибери **Build Video Downloader APK**. Натисни **Run workflow**, якщо збірка не запустилася автоматично після push.
4. Відкрий успішний запуск workflow унизу сторінки, секція **Artifacts**.
5. Завантаж `video-downloader-debug-apk`, розпакуй ZIP на телефон і встанови `app-debug.apk`. Якщо Android запитає, дозволь встановлення з цього джерела.

## Обмеження
- Потрібен прямий URL до відеофайлу. Посилання на сторінку фільму не є прямим посиланням.
- Деякі сервери блокують HTTP HEAD або вимагають авторизацію, cookies чи спеціальні заголовки; такі URL можуть не пройти перевірку.
- Застосунок не витягує приховані потоки, не обходить DRM, paywall чи інші технічні обмеження.
- Це debug APK для особистого тестування, не підписаний релізний пакет для публікації в Google Play.
